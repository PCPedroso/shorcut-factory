# 📂 Ícones das Redes Sociais — ViralCut

Esta pasta armazena os ícones oficiais das redes sociais utilizados na barra de assinaturas e badges dos cortes verticais (9:16).

---

## 📌 Nomes dos Arquivos Esperados

Coloque seus arquivos de imagem PNG (com fundo transparente) nesta pasta utilizando os nomes abaixo:

| Rede Social | Nome do Arquivo Recomendado | Nomes Alternativos Suportados |
| :--- | :--- | :--- |
| **YouTube** | `youtube.png` | `yt.png`, `youtube.svg`, `youtube.webp` |
| **Instagram** | `instagram.png` | `insta.png`, `ig.png`, `instagram.svg`, `instagram.webp` |
| **X (Twitter)** | `x.png` | `twitter.png`, `x_logo.png`, `x.svg`, `x.webp` |

---

## 🎨 Recomendações de Qualidade Visual

1. **Formato:** PNG com canal alpha (fundo transparente) ou SVG.
2. **Resolução Recomendada:** Imagens quadradas entre `128x128 px` e `512x512 px`.
3. **Cores:**
   - Você pode usar tanto a versão com as **cores oficiais da marca** (YouTube Vermelho, Instagram Gradiente, X Preto/Branco) quanto uma versão **monocromática branca** para um visual minimalista.
   - O sistema do ViralCut redimensiona automaticamente o ícone para mantê-lo milimetricamente proporcional ao tamanho da fonte configurado na interface.
